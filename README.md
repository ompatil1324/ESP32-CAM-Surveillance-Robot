# ESP32-CAM Surveillance Robot

Wi-Fi controlled surveillance robot using an AI-Thinker ESP32-CAM, OV2640 camera and L298N motor driver.

## Project Structure

- `src/` — ESP32-CAM Arduino source code
- `hardware/` — components, instruments and pin configuration
- `docs/` — project documentation

## Main Features

- Wi-Fi connectivity
- Live MJPEG camera streaming
- Browser-based robot control
- Forward, backward, left and right movement
- L298N dual-motor control

## Hardware

- AI-Thinker ESP32-CAM
- OV2640 camera
- L298N motor driver
- 2 × DC geared motors
- Robot chassis and wheels
- Battery and regulated power supply
- Jumper wires

See `hardware/Components_and_Instruments.txt` for the complete component list and wiring information.

## Software

The project is developed for the ESP32-CAM using Arduino IDE.

Before uploading the code, replace the Wi-Fi placeholders with your own credentials. Do not publish real Wi-Fi passwords or other private credentials.
