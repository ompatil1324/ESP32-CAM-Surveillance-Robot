ESP32-CAM SURVEILLANCE ROBOT
COMPONENTS & INSTRUMENTS LIST
================================

PROJECT:
Wi-Fi Controlled Surveillance Robot using AI-Thinker ESP32-CAM

1. MAIN ELECTRONICS
-------------------
1. AI-Thinker ESP32-CAM
   - Main controller
   - Wi-Fi communication
   - Camera interface
   - Web server

2. OV2640 Camera Module
   - Live video capture
   - Connected to the ESP32-CAM camera socket

3. L298N Motor Driver Module
   - Controls the two DC motors
   - Provides motor direction control

4. DC Geared Motors × 2
   - Left and right drive motors

5. Robot Wheels × 2
   - Connected to the DC geared motors

6. Caster Wheel × 1
   - Front/rear support for a two-wheel-drive chassis

7. Robot Chassis
   - Mechanical frame for mounting electronics and motors

2. POWER COMPONENTS
-------------------
1. Battery Pack
   - Main power source for the robot motors
   - Battery voltage must match the motor and L298N requirements

2. 5 V Regulated Power Supply / Buck Converter
   - Provides a suitable regulated supply for the ESP32-CAM

3. Power Switch
   - Main ON/OFF control

4. Battery Connector / Terminal
   - Battery connection to the robot power system

5. Jumper Wires
   - Male-to-male
   - Male-to-female
   - Female-to-female as required

6. Common Ground Connection
   - ESP32-CAM GND and L298N GND must be connected together

4. Wi-Fi Router / Mobile Hotspot

6. PIN CONFIGURATION
--------------------

AI-THINKER ESP32-CAM TO L298N

ESP32-CAM GPIO12 -> L298N IN1
ESP32-CAM GPIO13 -> L298N IN2
ESP32-CAM GPIO14 -> L298N IN3
ESP32-CAM GPIO15 -> L298N IN4

L298N OUT1/OUT2 -> Left DC motor
L298N OUT3/OUT4 -> Right DC motor

L298N ENA -> Jumper installed for full-speed Motor A
L298N ENB -> Jumper installed for full-speed Motor B

POWER

Motor battery + -> L298N motor supply (+12V/Vs, according to battery/motor voltage)
Motor battery - -> L298N GND
ESP32-CAM GND -> L298N GND

ESP32-CAM 5V -> regulated 5 V supply

IMPORTANT:
- Do not connect the motor battery directly to the ESP32-CAM unless its voltage is properly regulated and suitable.
- Keep all grounds common.
- GPIO12 and GPIO15 are ESP32 boot-strapping pins. If boot/programming problems occur, temporarily disconnect the L298N input wires while starting/programming the board.
- This project does not use the microSD interface.

7. FTDI / USB-TTL PROGRAMMING CONNECTION
----------------------------------------
FTDI 5V -> ESP32-CAM 5V
FTDI GND -> ESP32-CAM GND
FTDI TX -> ESP32-CAM U0R / GPIO3
FTDI RX -> ESP32-CAM U0T / GPIO1
GPIO0 -> GND during programming

After uploading:
1. Disconnect GPIO0 from GND.
2. Press RESET.
3. ESP32-CAM boots normally.

8. CAMERA

11. SAFETY / TESTING NOTES
--------------------------
- Check polarity before powering the circuit.
- Test motor direction with the wheels lifted from the ground first.
- Use a regulated supply for the ESP32-CAM.
- Do not short the battery terminals.
- Disconnect power before changing wiring.
- Verify the L298N and motor voltage ratings before connecting the battery.
